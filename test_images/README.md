# ADAS Test Images

This directory contains ten real images used by the CPU inference benchmarks.

| File | Scene | Source |
| --- | --- | --- |
| `adas_coco_000000000094_urban_road.jpg` | Urban road with vehicles | COCO train2017 image 94 |
| `adas_coco_000000000260_night_bus.jpg` | Low-light bus stop | COCO train2017 image 260 |
| `adas_coco_000000000359_lowlight_traffic_light.jpg` | Low-light traffic light | COCO train2017 image 359 |
| `adas_coco_000000000532_bus_pedestrians.jpg` | Bus and pedestrians | COCO train2017 image 532 |
| `adas_coco_000000000540_airport_roads.jpg` | Airport road network | COCO train2017 image 540 |
| `adas_coco_bike.jpg` | Bicycle, dog, vehicles and road | OpenVINO Notebooks sample data |
| `adas_huggingface_car.jpg` | Car close-up | Hugging Face documentation images |
| `adas_mapillary_empty_road.jpg` | Road, lane markings and signs | OpenVINO Notebooks / Mapillary sample |
| `adas_openvino_license_plate.png` | Vehicle and plate detail | OpenVINO Notebooks sample data |
| `adas_ultralytics_bus.jpg` | Bus and pedestrians | Ultralytics assets |

The COCO images are downloaded from `images.cocodataset.org`. Other images retain descriptive source prefixes in their filenames.
